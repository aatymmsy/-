# Security

Perch is a local application. Do not expose its management port to the public internet. Keep your data directory and API keys private. Full access and approved commands run with your operating system account's privileges.

Supported security fixes target the latest published source revision. This project is early-stage software; no independent security audit is claimed.

Please report vulnerabilities using [GitHub private vulnerability reporting](https://github.com/aatymmsy/-/security/advisories/new). Do not post credentials, private data, or an exploit involving another person's environment in a public issue. If private reporting is unavailable, open an issue containing only a request for a private reporting channel.
